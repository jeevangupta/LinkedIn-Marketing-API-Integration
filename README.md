# LinkedIn-Marketing-API-Integration
**This repository provides resources and code to help you integrate with the LinkedIn Marketing API.**

## What's included:

  ## Guides:
  - **Set Up LinkedIn Marketing API**: 
    A comprehensive guide that walks you through creating a LinkedIn developer account, configuring a LinkedIn API App, and enabling the Advertising API permission. This guide includes code examples for making your first API calls using Python.
    (Link: https://jeevangupta.com/linkedin-api-integration-a-complete-step-by-step-setup-guide/)
    
  - **How to get LinkedIn Campaign Analytics Data with Python**:
    A step-by-step tutorial on developing a Python script to extract valuable campaign performance data (Reporting or Analytics data) from your LinkedIn Campaign Manager Account using the LinkedIn Advertising API. 
    (Link: https://jeevangupta.com/extract-linkedin-campaign-reporting-data-with-python-a-step-by-step-guide/)

# Getting Started:

  ## Read the Guides:
  - Start with the "Set Up LinkedIn Marketing API" guide to understand the basic configuration process.
  - Once you have your credentials, follow the "How to get LinkedIn Campaign Analytics Data with Python" guide to build your Python script.
